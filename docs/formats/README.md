# Product evidence files

Every `*.md` here is generated by **`tools/unblock_mosdac.py`** from a
**real, authenticated MOSDAC download** (or a real file passed via
`--local`). Each carries the file's sha256, full attribute inventory,
decoded value ranges, and a parseability verdict.

- These files are meant to be **committed** — they ARE the "exact
  official product metadata" that gates activating a dataset connector.
- Nothing synthetic ever belongs here: the offline test suite
  (`pipeline/tests/test_unblock3.py`) builds its fixtures in tmp dirs
  and never writes to this folder.
- Regenerate: `python tools/unblock_mosdac.py` (see
  [MOSDAC_BLOCKED3_EVIDENCE.md](../MOSDAC_BLOCKED3_EVIDENCE.md)).
