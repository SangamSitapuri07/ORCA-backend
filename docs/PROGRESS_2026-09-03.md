# ORCA Progress — 3 September 2026 (Phase 4: app features)

## What shipped today

### New real data adapters (no dummy data anywhere)
- **`pipeline/incois_pfz.py`** — INCOIS's own GeoServer WFS serves the OFFICIAL
  daily PFZ advisory lines as GeoJSON MultiLineStrings (80 lines verified for
  Julian day 246 / 3 Sep 2026). Used for nearest-PFZ distance+bearing in the
  advisory card and for the green dashed map layer.
- **`pipeline/jtwc.py`** — JTWC RSS + warning products (`{id}web.txt`), browser
  User-Agent required. Parses position, max winds, movement and 34-kt wind
  radius. Live example: CS 'Krovanh' 40 kt. FINAL warnings are skipped.
- **`pipeline/forecast.py`** — hourly point forecast (waves/swell/current from
  marine API in UTC + wind/gust/rain in knots from forecast API) with
  `find_safe_window()`: first ≥3 h stretch with waves < 2.5 m, wind < 20 kn,
  gusts < 30 kn.
- **`pipeline/ttlcache.py`** — tiny in-process TTL cache.

### Deterministic engines
- **`pipeline/advisory.py`** — GO / CAUTION / NO-GO card. Rules are published
  small-craft/WMO/IMD thresholds (gale ≥ 34 kn gusts = NO-GO, waves ≥ 4 m,
  IMD heavy-rain 64.5 mm, cyclone < 300 km). Every reason cites its data.
- **`pipeline/alerts.py`** — threshold-driven REAL alerts + honestly-labelled
  DEMO simulation (`simulated: true`, 🧪 DEMO prefix) for the drill flow.
- **`pipeline/chat.py`** — rule-based chat brain (NO LLM yet by design):
  keyword router → actually runs the agents + tools → composes the answer
  from the returned numbers. Streams blueprint events (routing / agent_step /
  token / final).

### API (backend/main.py, v0.2.0)
- `GET /api/v1/advisory` — deterministic card (10-min cache per cell)
- `GET /api/v1/layers` — GeoJSON: official PFZ, cyclones + 34 kt radius,

- `GET /api/v1/alerts` · `POST /api/v1/alerts/simulate`

- `POST /api/v1/feedback` — persists to data/feedback.jsonl

- startup cache warm-up (PFZ lines, JTWC, Veraval advisory)
- first-touch cold advisory ≈ 60–90 s; warm = **~0.02 s** (verified)

### Bugs fixed (all real, found via live testing)
1. **INCOIS LAS "signal only works in main thread"** — SIGALRM is now only
   armed on the main thread (snapshot runs sources in worker threads).
2. **Marine Ecology agent returned empty results** — added the standard
   productivity/thermal-habitat profile + chlorophyll-gradient front proxy;
   never silent when data exists.
3. **Open-Meteo grid = diagonal** — the API zip-PAIRS the latitude/longitude
   lists (5 points), it does not cross-multiply (25). `get_sst_grid` now sends
   the full cartesian pair list. Live test got 5 → now 25 real points.
4. **Chlorophyll missing for "today"** — VIIRS has a ~3-day processing lag;
   the data layer steps back 3 days and surfaces `chlorophyll_date` honestly.
5. **Snapshot cache key drift** — `None` vs explicit today string keyed
   different caches; normalized so chat/advisory/reason share one snapshot.
6. **INCOIS/WFS/JTWC/cache** stats surfaced via `/api/v1/health`.
