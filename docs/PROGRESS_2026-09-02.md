### Key technical learnings

1. **Longitude convention varies by satellite.** EOS-06 uses 0-360°,
   JPSS2/VIIRS uses -180 to 180°. Must normalize per-file.
2. **NetCDF-3 vs NetCDF-4** — different magic bytes, same `netcdf4` engine
   in xarray handles both.
3. **Array shape matters.** EOS-06 files are 4D (time, lev, lat, lon)
   with leading singleton dims. JPSS2 L3 is 2D (lat, lon). Must collapse
   to (lat, lon) before indexing.
4. **Wind direction convention.** Meteorological = direction wind is
   blowing FROM. The math: `dir_from = (atan2(v, u) + 180) mod 360`.

### Chlorophyll limitation discovered

The single-day JPSS2 L3 file has only **11.5% valid cells** due to
Indian summer monsoon clouds blanking the Arabian Sea and Bay of Bengal.
This is a physical limitation of optical remote sensing, not a bug.
See `docs/CHLOROPHYLL_CLOUD_LIMITATION.md` for full analysis.
